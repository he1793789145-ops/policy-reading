# policy-reading

**让 AI 替你读政策原文，而不是替你复述新闻。**

你问「这个方向有没有机会」，大多数 AI 会给你一段听起来合理的乐观结论——方向词被放大，资金与项目被省略，文号是编的，你没法核对任何一句。

这个技能把它变成一份**可对质**的判读：每条关键结论都带文号、发布机关、发布日期、原文链接和逐字原句。你可以逐条点开核对。

它是给 AI agent 用的技能（skill），适用于 DeepSeek Harness 一类支持技能加载的宿主。

---

## 它会给你什么

一份固定骨架的报告，结论先行：

```
结论
  ├ 方向        一句话
  ├ 落地程度    只有概念 / 在落地 / 已落地
  ├ 依据        指向下面的证据
  └ 对你的意义  按你的类别与条件

证据表        文号 · 机关 · 日期 · 原文链接 · 逐字原句
跨年表        近 5 年逐年标注：有没有资金 / 项目 / 实施方案
产业链环节    这批钱落地后新增什么需求、谁增加投入
限制信号      与上面每条机会成对
低成本验证    一周内、千元内、必须触达真实客户
观察清单      盯什么、去哪看、下次什么时候看
证据不足      缺哪一类、因此哪些结论不可靠
```

**跨年表是关键。** 一个概念连续三年出现在政策里，却始终没有资金、没有项目、没有实施动作——报告会直接标它为「概念空转」，而不是继续给你画饼。

---

## 它挡掉的三件事

这三个约束是设计取舍，不是装饰：

**① 只报喜的判读会让人误判风险。**
任何一条「机会」旁边都跟着它的限制条件。政策给某个方向加码的同时，往往也在另一份文件里给相邻环节设限——两者必须一起看。

**② 「查不到」不许变成「应该有」。**
读不到的文件、核不实的文号，写进「证据不足」，档位记「不确定」。**查不到不得默认成有。** 这一条是为了让报告在缺证据时诚实降级，而不是用合理推测填空。

**③ 投资轨只给方向。**
不出标的、不给买卖时点、不估收益。这套方法的证据是政策文本与官方数据，它撑得起「什么需求会变大」，撑不起定价与择时。

## 快速开始

### 安装

把 `skill/` 复制到你的技能根目录，命名为 `policy-reading`：

```
<技能根目录>/
└── policy-reading/
    ├── SKILL.md
    ├── references/
    │   ├── method.md
    │   ├── judging.md
    │   ├── sources.md
    │   └── report.md
    └── scripts/
        ├── check_wenhao.py   文号核验
        └── read_pdf.py       读 PDF 附件
```

两个脚本都是可选增强：不装 Python 库也能用（`read_pdf.py` 自带纯标准库后端），技能正文不依赖它们，但缺了它们这两件事就会退回「凭手感」。脚本用 Python 3 运行，只用标准库；有 pypdf 时自动优先用它。

技能根目录通常是：

| 系统 | 路径 |
|---|---|
| Windows | `%USERPROFILE%\.dsh\skills\` |
| macOS / Linux | `~/.dsh/skills/` |

`SKILL.md` 必须在 `policy-reading/` 里**直接一层**，不要多套一层目录。

重启或新开会话后验证：输入 `/policy-reading`，或直接问一句政策问题看它是否自动接手。

### 第一次提问，带上你的条件

技能的第一步是「定轨」——**你要找的类别**（就业／创业／投资）、**所在地**、**已有的能力与资源**。这三项它不知道，就只能给通用结论，并在报告里标注「未按你的条件校验」。

```
我在县城做家电维修，想看看十五五规划里有没有跟我相关的机会
```

比「十五五有什么机会」有用得多。

手上有文件就直接给，比让它自己检索更准：

```
帮我读一下这份《XX 管理办法》征求意见稿，对我做 XX 有什么影响
```

### 只想要一部分

| 你说 | 它走 |
|---|---|
| （什么都不说） | 全流程八步 |
| 「我只想看懂这份文件」 | 只判读，不折算机会 |
| 「这个方向怎么样」 | 判断方向与落地程度，不推产业链 |

跳过的步骤会明确告诉你，并说明哪些结论因此不可靠。

## 八步流程

| # | 步骤 | 完成标准 |
|---|---|---|
| 1 | 定轨：类别、所在地、已有能力与资源 | 三项有答案，或记「未知」并标注未按条件校验 |
| 2 | 立检索面 | 入口落到具体 URL，标注能读到什么（全文／仅标题／读不到） |
| 3 | 成对取原文与官方解读 | 每个关键判断背后既有原文链接也有解读链接 |
| 4 | 判读三类表述 | 每条判断带文号＋机关＋日期＋链接＋逐字原句 |
| 5 | 落三问、拉跨年表、定三档 | 逐年标注资金／项目／方案，连续 ≥3 年只有概念标「概念空转」 |
| 6 | 折算到产业链环节 | 每个环节能追到至少一份文件的具体表述 |
| 7 | 机会与限制成对输出 | 没有落单的机会 |
| 8 | 低成本验证与观察清单 | 一周内、千元内、必须触达真实潜在客户 |

三类表述指的是：**鼓励类**（鼓励、支持、加快、发展、积极培育）、**推广类**（试点、示范、推广、扩大范围）、**限制类**（规范、整治、严控、淘汰、禁止）。前两类说明方向在被推进，第三类说明越来越难做。

## 它凭什么可信

仓库里带三组 **with / without 对照**：同一个问题，一次给技能、一次不给，输出并排比较。这是判断「它是否真的有用」最直接的方式，也是很多提示词仓库缺少的部分。

| 用例 | 问题 | 结果 |
|---|---|---|
| [县域家电维修](evals/iteration-1/eval-0-county-appliance/) | 十五五里有没有跟我相关的机会 | 技能赢在**可对质**：三份地方原文把「维修」写进中央财政资金支持方向，并抓到反向信号——补贴从 2024 年的 8 类家电、每件上限 2000 元，收窄到 2026 年的 6 类、只补 1 级能效、上限 1500 元 |
| [工信部征求意见稿](evals/iteration-1/eval-1-miit-design-draft/) | 对工业设计外包有什么影响 | 技能**输了**：无技能那份自己写了解析器读到 PDF 全文；有技能那份在 PDF 通路上失败，按纪律把条款记成「不确定」——没编，但把用户的真问题留成了空洞 |
| [养老要不要辞职](evals/iteration-1/eval-2-eldercare-quit/) | 都说养老是蓝海，要不要现在就辞职去干 | 技能赢在**证据与双向性**：拿到资金侧文号，以及最关键的反向信号——国办函〔2026〕14号要求养老机构「关停并转、有序退出」 |

第二行是仓库里最有价值的记录。它暴露了一个真实缺陷（技能当时放弃了 pypdf 这条通路），修订后做了[定向复验](evals/iteration-2/eval-1-miit-design-draft/)：同一个问题、同样的技能、不给任何提示，这一轮读出了征求意见稿全文。**修复有证据，不是口头声明。**

另外三份 with-skill 报告都主动申报了自己跳过的步骤与降级的证据。

> 评测是定性的，用来暴露缺陷和校准触发描述，不是 benchmark。

## 仓库结构

```
policy-reading/
├── skill/                  ← 技能本体（安装这个）
│   ├── SKILL.md            八步流程与完成标准
│   ├── references/         按需加载：方法论、判读词表、源清单、报告骨架
│   └── scripts/            可选：文号核验、PDF 读取
├── CONTEXT.md              23 个术语的 glossary
├── docs/adr/               7 条决策记录
└── evals/                  3 组 with/without 对照 + 1 组复验
```

**为什么方法论不放在主文件里**：每次会话都常驻的正文，每个字都要付 context 成本。八步流程是每次都要走的，所以放在 `SKILL.md`；方法论全文是「读到才需要」的材料，放在 `references/` 按需加载。详见 [ADR-0001](docs/adr/0001-process-in-skill-method-out-of-body.md)。

术语表里每个词都带 `_Avoid_` 行，明确**不该用什么词代替**——比如「政策机会」不能用「风口」「蓝海」来代替，因为一旦用上这些词，判读就会滑向情绪。

## 已知限制

- **依赖一个非公开检索接口。** 主入口是 `sousuo.www.gov.cn/search-gov/data`，今天能用、官方不承诺、随时可能失效。失效时退回「请用户贴原文」。详见 [源清单](skill/references/sources.md)。
- **地方站点差异大。** 部分地方政府门户的列表页是 JS 渲染，读不到；县级站点覆盖尤其不稳定。
- **征求意见稿没有全国统一聚合页**，只能按部委分别采。
- **它不预测涨跌。** 政策告诉你资源往哪里配，不保证进去就赚钱。报告最后一步永远是低成本验证，不是让你先辞职。
