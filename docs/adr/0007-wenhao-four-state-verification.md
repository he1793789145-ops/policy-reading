# 文号核验分四态，未命中不等于造假

文号核验不是「搜到就算真」，而是取回结果后与 `pcode` 精确比对，并分成四态：`OK`（精确命中）/ `NO-RECORD`（索引无此号）/ `NEAR-MISS`（有近似号但精确未命中）/ `AMBIGUOUS`（裸号命中多份）。理由是虚构文号会被搜索引擎以「近似号」返回——`财债〔2026〕14号` 确实返回 3 条结果，命中的却是 `国发〔2026〕14号`、`财办建〔2026〕14号` 这类编号相近的真文件，只看「搜到了」就会把它当真的，这正是此前的虚构文号没被发现的机制。同时必须保留 `NO-RECORD` 这个不置可否的态：部委自有站点发布、未进政策文件库的文件（如 `工信部政法〔2023〕93号`）确实查不到，把「查不到」说成「不存在」会制造新的错误。代价是核验要联网，且 `NO-RECORD` 只能靠人回原文判断，不能自动裁决。
