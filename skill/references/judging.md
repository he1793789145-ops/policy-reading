# 判读参考

## 三类表述

下表是**判读时的参考，不是可引用的凭据**。写进报告的任何实例都必须自己核到文号＋原句；本表的示例未经逐条核验。

| 类 | 表述 | 含义 | 2026 年的实例 |
|---|---|---|---|
| 鼓励类 | 鼓励、支持、加快、发展、积极培育 | 方向在被推进 | 政府工作报告 2026：“打造一批国家先进制造业集群” |
| 推广类 | 试点、示范、推广、扩大范围 | 已走出探索，进入范围应用 | 家电以旧换新：2024 年商办流通函〔2024〕397号、2025 年〔2025〕6号、2026 年 2025 年第 469号，试点连续扩面并逐年加码 |
| 限制类 | 规范、整治、严控、淘汰、禁止 | 越来越难做，或将被叫停 | 政府工作报告 2026：“综合整治‘内卷式’竞争”“加快淘汰落后产能” |

限制类的强度递增：规范（活动继续、规则变清）→ 整治（点名治理）→ 严控（设上限）→ 淘汰（退出）→ 禁止（绝对）。出现“有序”“分类”会软化时间表。

## 判据：有资金、有项目、有方案

一条鼓励性表述要变成事实，通常在同一份或配套文件里出现下列之一：

| 词 | 通常出现在 | 变成事实的标志 |
|---|---|---|
| 中央预算内投资 | 发改委专项管理办法、预算报告 | 专项管理办法里的“支持范围／补助标准” |
| 超长期特别国债 | 政府工作报告、预算报告 | “两重”项目清单、投资计划下达 |
| 地方政府专项债券 | 报告／预算、财政部债务管理司 | 项目清单、“自审自发”试点范围 |
| 专项资金 | 部门通知＋资金管理办法 | 资金管理办法＋申报指南 |
| 转移支付 | 报告／预算、预决算公开平台 | 中央对地方转移支付表 |
| 政府投资基金／引导基金 | 报告、规划纲要 | 基金设立公告＋管理办法 |
| 贴息 | 财政部（常会同人民银行、金融监管总局）通知 | 贴息范围、比例、期限 |
| 风险补偿 | 报告、财政金融政策 | 与贴息／担保同现才具体 |
| 以奖代补 | 规划纲要、专项资金管理办法 | 绩效考核办法 |
| 首台（套） | 规划纲要、工信与财政政策 | 推广应用指导目录＋保险补偿 |
| 揭榜挂帅 | 规划纲要、科技专项通知 | 发榜单位＋任务榜单 |
| 场景开放 | 规划纲要、行动方案 | 场景清单发布 |
| 沙盒监管 | 规划纲要 | 无（实验性，不含资金） |
| 示范项目／试点城市 | 部门通知 | 名单公示 |
| 产业集群／国家先进制造业集群 | 规划纲要、报告 | 集群名单、竞赛结果 |
| 专精特新／小巨人 | 工信与财政政策、三年行动方案 | 梯度培育名单 |

读到**名单／目录／申报指南**才算跨过“有项目”的门槛；只有词组、没有名单的，记为“只有概念”。

## 文种与约束力

| 文种 | 约束力 | 怎么读 |
|---|---|---|
| 通知 | 部署动作与时限，实质在附件《…》里 | 找附件名与发文对象 |
| 意见（指导意见／若干意见） | 方向性＋政治承诺，很少自动执行 | 看有没有配套通知 |
| 办法 | 约束性程序，常以部门令发布 | 生效日期、罚则、申报条件 |
| 规定 | 比办法更窄、更禁止 | 看禁止项与处罚 |
| 条例 | 行政法规，可强制执行 | 施行日期 |
| 规划 | 方向性但有指标与重大工程；约束性指标硬、预期性软 | 找约束性指标与重大工程清单 |
| 纲要 | 最高层方向，几乎无执行机制 | 只用作定位，不当作落地证据 |
| 方案（实施／行动／三年行动） | 操作性最强：任务、责任单位，有时有数字 | 项目落点的首选 |
| 公告 | 通知事实或市场措施，无政策方案 | 当作事实，不当作方向 |
| 批复 | 批准他人已拟好的文本，内容在被批的那份里 | 去要被批的原文 |
| 决定 | 修改类决定有条例级效力 | 看改了哪一条 |
| 细则 | 条例／办法下的操作细节 | 最贴操作层 |
| 指南／指引 | 非约束性技术指引 | 看主管部门接受什么 |
| 目录／清单 | 枚举性，划定谁有资格 | 钱的真正闸门 |
| 白皮书 | 官方叙事，零约束力 | 只用官方叙述与数据 |
