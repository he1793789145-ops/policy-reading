## 主入口：gov.cn 检索接口

```
https://sousuo.www.gov.cn/search-gov/data?t=<TYPE>&q=<关键词>&p=1&n=10
```

- `t=zhengcelibrary_gw` 国务院文件｜`t=zhengcelibrary_bm` 国务院部门文件｜`t=zhengce` 政策频道（含中央文件）
- 加 `&searchfield=title` 只搜标题，默认 `quanwen` 全文
- 返回：`pcode`（文号）、`puborg`（发布机关）、`pubtimeStr`（日期）、`url`（原文直链）、`summary`（摘要）、`childtype`（主题分类）；`groupMap` 按文种计数（国令／国发／国函／国办发／国办函／国发明电／国办发明电），`facetMap` 可按年份与主题收敛

**怎么取**（这几条不写下来一定踩）：

- 用抓取工具取这个 URL。**不要用 shell 直连**——沙箱的网络栈会断，症状是 TLS／连接被关闭，很容易被误判成“接口失效”而整条放弃主入口。
- `n` 取小（3–10）。返回体里的 `ztflTree`、`catMap` 是大块分面，扫标题时加 `&searchfield=title`；**不要把分面体当正文读或复制进报告**。
- 量级要心里有数：一次 `n=5` 的响应里，`listVO`（你要的结果）只占很小一部分，`ztflTree`＋`catMap` 会把分面体重抄一遍，是主要体积来源。所以只用抓取工具取，**不要把整个响应贴进上下文或报告**——只取 `listVO` 的字段。`n` 越大分面越吞上下文，反而可能看不到结果。
- 这是非公开接口：今天能用，官方不承诺，随时可能失效。失效时退回“请用户贴原文”。

## 附件怎么读

征求意见稿与申报指南的正文常常在 PDF 附件里（工信部尤其如此），而**抓取工具读不了 PDF**（返回“不支持的内容类型”）。按顺序试：

1. **直取文件直链**：附件通常在 `www.miit.gov.cn/cms_files/.../*.pdf` 这类路径上，带 Referer 与 User-Agent 直接取二进制。注意工信部页面上给的 `jyhwzhq.miit.gov.cn` 直链会 403，**把主机换成 `www.miit.gov.cn`、路径照抄就是 200**——这一步救回过整份征求意见稿。镜像站与公共代理常常 403 或 5xx，别在上面耗时间。
2. **用 pypdf 读（先试这条）**：先探一下有没有可用的 pypdf，别直接放弃。
   ```
   python -c "from pypdf import PdfReader; print('ok')"
   ```
   - 成功 → 直接读：`python -c "from pypdf import PdfReader; print(PdfReader('x.pdf').pages[0].extract_text())"`（中文前提是 PDF 带 ToUnicode CMap）。
   - 失败（`ModuleNotFoundError`）→ 换一个解释器再试。很多环境里**PATH 上的 `python` 与 agent 运行时捆绑的 Python 是两个不同的解释器，能力不同**：捆绑的那个常常不带任何 PDF 库，而系统装的可能带 pypdf。
   - 都不行 → 走第 3 条手工解。
3. **手工解（没有 pypdf 时）**：只有标准库时用 `zlib` 解 FlateDecode、按 `ToUnicode` CMap 还原字符、按 `Tm` 重建行，可以在内存里拿到全文，不落盘。值得做的前提是**附件承载关键证据**（门槛、指标、申报条件、金额）。一个会卡很久的坑：按 `Tm`／`Td` 重排文本时，`TD` 的位移要乘 `Tm` 的缩放因子（常见 0.05），否则整页字符交错、读出来的数字全是错的。
4. **退回**：以上都不通时请用户贴正文，并把缺口写进「证据不足」。用二手转述填这个洞是不行的。

## 三部委看什么

- **发改委**——投向与项目：`/xxgk/zcfb/tz/` 里找“中央预算内投资专项管理办法”“下达投资计划”“重大项目”；产业与专项规划在 `/xxgk/zcfb/ghwb/`（栏目是否可读需现场确认）。
- **工信部**——制造业、数字经济、产业升级：政策文件与解读走单品页；意见征集是**全文可读**的，重点看“起草说明＋附件”。
- **财政部**——钱从哪出：政策发布页；专项资金及其管理办法；预决算公开平台的“中央对地方转移支付”；专项债看债务管理司文件（如“自审自发”试点范围）。

三者合看：发改委给方向与项目，工信部给产业落点，财政部给力度与资金形态。

## 地方：定位法（不背清单）

按顺序找，每一步用“关键词＋年份”在站内检索：

1. 本级政府门户 → “政策文件／政策解读”栏目，找**实施方案、行动方案、若干措施**
2. 主管部门（工信局／发改委／人社局／农业农村局……）→ 对应国家方向的落地文件
3. 财政局与发改委 → 资金公示、项目公示、专项资金管理办法、专项债项目清单
4. 政府门户 → 意见征集／公示公告（地方版预期窗口）
5. 产业园区与人才政策 → 搜“招商”“人才”“补贴”“申报指南”；**申报指南里的门槛就是资格线**

判断地方文件含金量的动作：看有没有**配套资金、项目清单、申报指南**三样中的任一样。只有转发和口号的地方文件，视同没有落地。
